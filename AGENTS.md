# Instrucciones del repositorio

## Flujo de Git

- Cuando el usuario diga "pusheá" o "push", hacer commit y push sobre la rama actual.
- No crear ni cambiar de rama salvo que el usuario lo pida explícitamente.
- No abrir un pull request salvo que el usuario lo pida explícitamente.
- Si la rama actual no tiene upstream, configurarlo contra una rama remota del mismo nombre.
